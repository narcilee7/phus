# 命令参考

Phus CLI 所有命令一览。

## 命令列表

| 命令 | 说明 |
|---|---|
| `phus` | 启动 TUI（默认） |
| `phus setup` | 交互式配置向导 |
| `phus run <prompt>` | 单次 prompt 执行 |
| `phus chat` | 交互式聊天模式 |
| `phus gateway` | 启动 Gateway 服务 |
| `phus tasks` | 显示任务状态 |
| `phus skills` | 列出已安装技能 |
| `phus health` | 健康检查 |
| `phus logs` | 查看日志 |
| `phus tape` | 查看 Tape 历史 |
| `phus policy` | 查看安全策略 |
| `phus profiles` | 管理 Provider 配置 |
| `phus compact <session>` | 压缩会话 |
| `phus trace <session>` | 追踪会话 |
| `phus resume <session> [prompt]` | 恢复会话 |
| `phus hooks` | 列出已注册 Hooks |
| `phus plugins-list` | 列出已加载插件 |
| `phus metrics` | 查看运行时指标 |

## 全局选项

| 选项 | 说明 |
|---|---|
| `--help` | 显示帮助 |
| `--version` | 显示版本 |
