# phus tasks

显示 Agent 状态、任务、调度和 Checkpoint。

```bash
phus tasks [选项]
```

## 选项

| 选项 | 说明 |
|---|---|
| `--json` | JSON 格式输出 |

## 输出示例

```

│ Sessions: 3                                                │

│   • session-def456                                          │
│   • session-ghi789                                          │
├─────────────────────────────────────────────────────────────┤

```
