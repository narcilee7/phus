## 页 3 — 转折：「西西弗斯的启发」

**标题**: 「如果西西弗斯能进化呢？」

**叙事**: 
- 加缪的西西弗斯：推石上山，石头滚落，周而复始
- Phus 的西西弗斯：推石上山，**学会技巧**，下次推得更高

**视觉**: 左右对比。左边：推石→掉落→推石（灰色循环）。右边：推石→掉落→**反思**→**写技能**→推更高（金色螺旋上升）。中央转场箭头 + 「Tape 记录每一轮」标注。

**一句话**: 「Phus 的核心理念：重复不是诅咒，是进化的燃料。」

## 页 4 — Phus 是什么（一句话 + 架构全景）

**标题**: 「Phus = LLM + 工具 + 进化引擎」

**架构图**（自上而下）:
```
Channel（CLI / TUI / WebSocket / Telegram / Slack）
        ↓
Hook 链（7 阶段 · 17+ 挂载点）
        ↓
Pi Agent（LLM 循环 + 工具调用）
        ↓
Tape（SQLite 只追加持久化）
        ↓
Evolution Engine（反思 → 技能草案 → A/B 验证）
```

**视觉**: 流程图式，每层一个色块，从冷色渐变到暖色（底部进化层用金色）。右侧标注：「4 个包，单向无环依赖」「Node ≥ 20 · TypeScript · pnpm monorepo」

## 页 5 — 核心亮点 1：「会写技能的 Agent」

**标题**: 「14 个元工具，让 Agent 自我改造」

**叙事**: 「普通 Agent 用工具干活，Phus 用工具进化自己。」

**三列卡片**:

| 🛠 技能系统 | 🧠 记忆系统 | 🔬 进化系统 |
|---|---|---|
| skill_write | memory_write | reflect |

**关键能力**:

- ✅ **闭环**: 经验 → 技能 → 验证 → 改进

**底部金句**: 「第 100 次对话的 Phus，比第 1 次更强。」

## 页 6 — 核心亮点 2：「Plan + SubAgent 执行引擎」

**标题**: 「分解大任务，并行执行，永不污染上下文」

**叙事**: 「你以为只能一问一答？Phus 会自己做项目规划。」

**DAG 调度示意**:
```
目标 → [检查] → [编辑, 测试]（并行）→ [修复] → 完成
          │          │
          └─ SubAgent ┘（独立 Agent，私有消息历史）
```

**关键数据**:
- 📋 多步骤 DAG 拓扑排序，同层并行（最多 3 个）
- 🔒 SubAgent 私有上下文，**绝无污染**
- 💾 计划持久化 SQLite，重启不丢失
- 🔄 失败自动 replan

**底部**: 「Plan 是元工具——Agent 可以自己调用 plan_create」

## 页 7 — 核心亮点 3：「安全第一」

**标题**: 「Agent 和你在同一个安全边界内」

**叙事**: 「能力强了，安全不能成为事后补丁。」

**三层防护**:
- 🛡️ **文件写入白名单**: 仅 `./skills/` `./.phus/` `./tmp/` `./out/`
- ⚠️ **危险命令拦截**: `rm -rf /` · fork 炸弹 · `curl|sh` · `mkfs` · `chmod -R 777 /`

**视觉**: 三环嵌套图，最外环「所有频道」，中间「所有工具」，内核「安全策略」。SubAgent 标注：「同样的护栏，零逃逸通道」

## 页 8 — 快速上手：「3 条命令跑起来」

**标题**: 「从零到对话，30 秒」

```bash
# 1. 安装
pnpm install

# 2. 设置 API Key
export ANTHROPIC_API_KEY=sk-ant-...

# 3. 启动
pnpm dev          # TUI 模式
pnpm run "..."    # 单次执行
pnpm gateway      # 多通道网关
```

**一键部署**:
```bash
brew tap narcilee7/phus && brew install phus   # Homebrew
docker compose up -d                             # Docker
```

**视觉**: 终端风格代码块，深色背景，语法高亮。右侧放一个 TUI 截图缩略图。
