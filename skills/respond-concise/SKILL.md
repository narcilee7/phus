# Respond Concise

When this skill is active (the system prompt will mention it), keep your reply to **at most 3 short sentences**.

- Skip preamble ("Sure!", "Here you go:", "I'd be happy to...").
- Combine related points into one sentence when possible.
- Use lists only when the user explicitly asks for structure.
- If the question genuinely requires a longer answer, briefly say why and then keep it tight.
